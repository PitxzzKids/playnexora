# Area fitur dan checklist pengujian

Setelah menjalankan aplikasi, uji area berikut: login dan peran Siswa/Guru/Admin; navigasi desktop/mobile; pencarian menu; materi dan aktivitas pembelajaran; simulasi/lab jaringan; misi/tantangan; kuis/evaluasi; XP/rank/achievement; progres; ekspor dan impor cadangan; suara, animasi, dan scrolling.

Checklist:
- [ ] Halaman terbuka tanpa aset lokal 404.
- [ ] Login dan pemilihan peran berjalan.
- [ ] Navigasi desktop dan mobile berfungsi.
- [ ] Materi, simulasi, misi, dan evaluasi dapat dibuka.
- [ ] Progres tersimpan setelah refresh pada browser yang sama.
- [ ] Ekspor dan impor cadangan berhasil.
- [ ] Tampilan diperiksa pada layar HP dan laptop.
- [ ] Console browser diperiksa untuk error JavaScript.
