Kamus Istilah Jaringan

Cari istilah untuk melihat penjelasan singkatnya.

Default Gateway

Alamat perangkat router yang menjadi jalur keluar host menuju jaringan lain.

DNS

Layanan yang menerjemahkan nama domain menjadi alamat IP.

DHCP

Protokol yang membagikan konfigurasi IP secara otomatis kepada klien.

VLAN

Segmentasi jaringan Layer 2 menjadi beberapa broadcast domain secara logis.

NAT

Teknik menerjemahkan alamat IP, misalnya alamat privat ke alamat publik.

ARP

Protokol IPv4 untuk mencari alamat MAC berdasarkan alamat IP pada jaringan lokal.

Trunk

Link switch yang membawa trafik dari beberapa VLAN menggunakan penandaan VLAN.

CIDR

Notasi prefix seperti /24 untuk menunjukkan panjang bagian network pada alamat IP.

SWITCHING WORKSHOP • VLAN SEGMENTATION

Misi 1: Atur VLAN

Ubah VLAN perangkat melalui labelnya. Pilih mode pemilihan pengirim atau tujuan, lalu ketuk perangkat pada topologi untuk menentukan alur paket.

Mode aktif: pilih perangkat pengirim.
PENGIRIMBelum dipilih
TUJUANBelum dipilih
Inter-VLAN Routing / Router Layer 3Mati
Pilih pengirim dan tujuan melalui tombol mode di atas.

Konsep dan aturan simulasi

VLAN membagi satu switch menjadi beberapa broadcast domain. Perangkat pada VLAN yang sama dapat berkomunikasi langsung. Perangkat lintas VLAN memerlukan perangkat Layer 3 dengan inter-VLAN routing.

VLAN 10 GuruVLAN 20 SiswaVLAN 30 Server
Latihan: pilih PC Siswa sebagai pengirim dan Server sebagai tujuan. Kirim paket saat routing mati, aktifkan routing, lalu kirim ulang.
Access portPort ke PC/server membawa satu VLAN.
Broadcast domainBroadcast VLAN 10 tidak otomatis masuk ke VLAN 20.
Inter-VLAN routingRouter atau switch Layer 3 meneruskan trafik antarjaringan.

Misi 2: Bagi subnet

Geser prefix dan lihat bit jaringan (terang) dan bit host (redup) berubah.

Tantangan kapasitas

Lab TJKT butuh 50 host dalam satu subnet. Prefix terbesar (subnet terkecil) yang masih cukup adalah?

Rumus: host usable = 2(32 − prefix) − 2. Dua alamat dipakai untuk network dan broadcast.

NETWORK PLANNING TOOL

Kalkulator Subnet IPv4

Hitung network ID, broadcast, subnet mask, rentang host, dan prefix berdasarkan kebutuhan jumlah perangkat.

Masukkan alamat, prefix, dan jumlah host untuk mulai menghitung.
NETWORK ID192.168.10.0
BROADCAST192.168.10.255
SUBNET MASK255.255.255.0
HOST USABLE254
Rekomendasi untuk 50 host: /26 dengan 62 host usable.

Catatan: kalkulator memakai aturan subnet IPv4 umum untuk LAN. Prefix /31 ditampilkan sebagai jaringan point-to-point dan /32 sebagai satu alamat host.
